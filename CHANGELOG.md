# Changelog

The repository begins from the reviewed **October 2026** Pine v6 script. The source is maintained as a single canonical file.

## Initial public release — 2026-10-19

- Published the standalone reviewed TD Sequential and Combo indicator.
- Included deferred 13 and optional 8-versus-5 qualification, immediate/later Setup perfection, configurable Combo variants and explicit recycling rules.
- Kept multiple TDST support/resistance records live independently of rendering; added visible-price-range filtering, live/hidden table counts and historical qualified-break segments.
- Made TDST appearance configurable: **1 px dotted before qualification**, **1 px solid after a qualified break**, with independent line style and width controls.
- Defaulted the TDST starting coordinate to the exact Setup 1 candle.
- Included optional Sequential risk-reference levels and confirmed-bar alert conditions.
- Documented non-official methodology, rule differences, historical backfill and validation limitations.

Earlier versions were developed outside this repository. No external test logs or historical commits are represented as files in this initial import.
